# 细胞模拟 V8

二维细胞模拟实验：从一个细胞开始，通过代谢、生长、分裂、局部分化、营养与废物运输、接触通信和协同出芽，观察组织形成与较大子团繁殖。

这是当前 V8 的精简源码包。旧 Python 研究代码、旧版成品和完整实验数据保留在原项目中。包内共用核心仍含 V6/V7 兼容分支，避免删减分支改变已验证行为。

## 直接运行

从仓库的 Releases 页面下载 `细胞模拟V8.exe`，适用于现代 64 位 Windows，无需 Python、Anaconda 或编译器。启动时只有一个细胞，处于暂停状态。点击“运行”或按空格开始。

可选择 19 种观察视图，查看胞内糖/废物、真实运输箭头、分化、出芽通信和谱系。只要还有活细胞就持续运行；全灭后才开启下一轮。镜头由用户缩放和拖动。

EXE 单独发布，不放入源码压缩包。跨电脑兼容性尚未全面实测。

## 文件

| 目录 | 用途 |
|---|---|
| `native/` | 模拟核心、界面和构建脚本 |
| `configs/v8.json` | V8 默认实验参数 |
| `tools/` | 原生局部机制测试与十种子批量验收 |
| `docs/` | 当前机制说明、验收摘要和整理说明 |

## 构建

在 Windows PowerShell 中，从项目根目录运行：

```powershell
./native/build.ps1 -CompilerPath C:/msys64/ucrt64/bin/g++.exe
```

使用自己已有的编译器路径。精简包的构建脚本默认选择 V8；生成 `output/release-v8/细胞模拟V8.exe`。不修改系统 PATH，不自动下载工具。

## 验证

编译并运行原生局部机制测试：

```powershell
./tools/run_local_tests.ps1 -CompilerPath C:/msys64/ucrt64/bin/g++.exe
```

批量验收需要 Python 3.10 或更高版本，仅使用标准库：

```powershell
python tools/verify_native_v8.py --checks
```

默认运行 10 个固定种子，每种 7500 步（300 模拟时间单位）。要求至少 8/10 通过。此工具会生成实验数据，建议预留磁盘空间；不应把缩短观察窗后未出芽直接解释为模型故障。

当前精简包不包含旧 V6 成品，批量工具中的旧成品对比项会跳过；本地原项目保有该对照。

## 已有证据和限制

2026-10-14 的首轮 V8 验收为 8/10，登记子团为 48–204 个细胞。种子 2 没有在窗口内登记子团；种子 5 的小组件比例过高。候选可能重新融合。

信号通过真实接触逐步接力，通信和运动消耗糖。谱系登记只用于统计，不控制运动或改写基因。

模型单位未经真实生物数据标定。出芽验收不等于长期进化、真实器官或完整双网络损伤验收。实时窗口性能也不能由离线绘图耗时直接推算。

详见 [V8 说明](docs/V8.md)、[验收摘要](docs/verification/V8.json)与[整理说明](docs/PACKAGE.md)。
